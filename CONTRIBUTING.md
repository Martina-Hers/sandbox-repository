# Contributing

1. Crea o asigna un Issue.
2. Crea una rama desde `main`: `feature/<descripcion>` o `fix/<descripcion>`.
3. Haz cambios pequenos y ejecuta `npm run ci`.
4. Haz push a tu rama y abre un Pull Request.
5. Espera a que pasen CI, CodeQL y Dependency Review.
6. Resuelve comentarios y vuelve a hacer push si es necesario.
7. Haz merge solo cuando las reglas del repositorio lo permitan.
