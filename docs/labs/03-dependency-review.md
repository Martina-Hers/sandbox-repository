# Lab 03 - Dependency Review

1. En una rama nueva ejecuta `npm install <una-libreria-de-practica>`.
2. Confirma que cambian `package.json` y `package-lock.json`.
3. Abre un PR.
4. Abre el check `Dependency Review / scan` y observa el cambio de dependencias.
5. No agregues deliberadamente paquetes conocidos como vulnerables solo para forzar un fallo.
