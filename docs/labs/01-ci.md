# Lab 01 - GitHub Actions CI

1. Crea un Issue: "Cambiar el umbral de aprobacion de 10000 a 12000".
2. Crea `feature/change-approval-threshold`.
3. Cambia solo el codigo, no los tests.
4. Abre un PR: el test debe fallar.
5. Actualiza los tests y vuelve a hacer push.
6. Verifica que `CI / validate` cambie a exitoso.
