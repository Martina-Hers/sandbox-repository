# Lab 05 - CodeQL

1. Haz un PR normal y abre el check `CodeQL / javascript-typescript`.
2. Revisa la pestana Security > Code scanning.
3. Para practicar hallazgos, usa ejemplos educativos controlados y documentados; no introduzcas vulnerabilidades en un repo real.
4. Si habilitas CodeQL Default Setup desde la UI, elimina/deshabilita el workflow avanzado `codeql.yml` para evitar duplicacion.
