# Lab 02 - Branch protection

1. Configura el ruleset/proteccion de `main` usando `docs/github-settings.md`.
2. Intenta completar un PR con un check fallido.
3. Confirma que GitHub bloquea el merge.
4. Corrige el cambio y confirma que el merge vuelve a estar disponible.

Si estas solo, no exijas aprobaciones hasta invitar a un colaborador de practica.
