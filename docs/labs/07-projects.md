# Lab 07 - GitHub Projects

1. Crea un Project llamado `GitHub Corporate Sandbox`.
2. Crea un Issue y agregalo a Backlog.
3. Muevelo a In Progress al crear la rama.
4. Abre un PR con `Closes #<issue>` y mueve la tarjeta a In Review.
5. Tras el merge, confirma que el Issue se cierra y mueve la tarjeta a Done.
