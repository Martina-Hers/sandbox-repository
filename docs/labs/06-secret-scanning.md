# Lab 06 - Secret scanning

1. Habilita Secret scanning y Push protection si tu repositorio/plan lo permite.
2. Confirma que `.env` esta ignorado y `.env.example` solo contiene placeholders.
3. No uses un PAT, password, API key o token real como material de prueba.
4. Si tu entorno permite patrones personalizados de secretos, crea un patron exclusivamente sintetico para laboratorio y pruebalo con un valor falso.
